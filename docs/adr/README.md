# Registre des Architecture Decision Records

Les ADR documentent **pourquoi** une décision structurante a été prise, ses alternatives et ses conséquences. Ils ne remplacent ni les exigences ni les tâches.

| ID | Décision | Statut |
| --- | --- | --- |
| [0001](0001-context-single-source.md) | Une source de vérité pour les règles communes | Accepted |
| [0002](0002-human-governance.md) | Revue humaine des modifications de gouvernance | Accepted |

Créer une nouvelle décision depuis [0000-template.md](0000-template.md).

## Cycle de vie

`Proposed → Accepted` ou `Rejected`. Une décision acceptée peut ensuite devenir `Superseded` par un **nouvel** ADR. Éviter de modifier silencieusement les raisons historiques. Garder un lien `Superseded by` / `Supersedes` et une date.

Les ADR 0001 et 0002 portent sur **ce template** ; un projet qui le copie doit confirmer leur applicabilité.
